## What this project is

A React component application built with JSX, state and hooks, written to satisfy the user stories set by
freeCodeCamp for this certification project. It is part of the Front End Development Libraries v9 curriculum,
whose certification requires completing all coursework plus this set of certification projects
and passing the certification exam.

- **Curriculum:** freeCodeCamp Front End Development Libraries (v9)
- **Project type:** Certification project
- **Tech stack:** React, JavaScript, HTML5, CSS3
- **Challenge page:** <https://www.freecodecamp.org/learn/front-end-development-libraries-v9/lab-tic-tac-toe/lab-tic-tac-toe>

## Project files

- `App.jsx` — React component (JSX)
- `index.html` — page markup and structure
- `styles.css` — styles and layout

## How to run

The React source is provided as JSX (`App.jsx`). To run it locally, use any
JSX-capable setup (Vite, Create React App, or the freeCodeCamp editor), or open the
challenge page and paste the files into its editor.

## User stories

The full list of user stories is included in this repository's challenge documentation on
freeCodeCamp: <https://www.freecodecamp.org/learn/front-end-development-libraries-v9/lab-tic-tac-toe/lab-tic-tac-toe>

Every user story is satisfied by the implementation in this repository — all freeCodeCamp
